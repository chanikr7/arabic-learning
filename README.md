# לימוד ערבית – תרגול אוצר מילים

דף אינטרנט לתרגול אוצר מילים בערבית מדוברת, לדוברי עברית.
בונים רשימות של מילים (עברית – ערבית – תעתיק) ומתרגלים אותן בשלושה משחקים.

**הדף החי:** https://chanikr7.github.io/arabic-learning/

## איך זה בנוי

- **הדף** – קובץ HTML אחד (`index.html`) שמתארח ב-GitHub Pages. אין שרת משלו ואין שלב בנייה.
- **הנתונים** – הרשימות נשמרות במסד נתונים ב-Supabase, ולכן הן זהות בכל מחשב ובכל דפדפן.
- **המילים** – מוסיפים אותן מ[מילון מדרסה](https://milon.madrasafree.com/) בעזרת סימנייה, או מקלידים ידנית.

## קבצים

| קובץ | מה זה |
|---|---|
| `index.html` | הדף עצמו: ניהול רשימות ושלושת המשחקים |
| `bookmarklet-install.html` | דף להתקנת הסימנייה שמוסיפה מילים ממילון מדרסה |
| `bookmarklet-src.js` | קוד המקור הקריא של הסימנייה |
| `backup.py` | סקריפט פייתון שמגבה את הרשימות מ-Supabase לקובצי JSON |
| `.github/workflows/backup.yml` | הגדרת ההרצה האוטומטית של הגיבוי ב-GitHub Actions |
| `backups/latest/` | הגיבוי האחרון: קובץ JSON לכל רשימה |

## הוספת מילים

### מהמילון, בעזרת הסימנייה

התקנה חד-פעמית: פותחים את [דף ההתקנה](https://chanikr7.github.io/arabic-learning/bookmarklet-install.html) וגוררים את הכפתור הירוק לסרגל הסימניות.

ואז, בכל פעם:

1. מחפשים מילה במילון מדרסה ונכנסים לדף המילה.
2. לוחצים על הסימנייה. נפתחת חלונית עם העברית, הערבית והתעתיק, ואפשר לתקן אותם.
3. בוחרים רשימה או יוצרים חדשה, ולוחצים "הוסף לרשימה" (או Enter).

המילה נשמרת מיד בענן. דף התרגול מתעדכן כשחוזרים ללשונית שלו.

התוכן במילון שייך למדרסה, והשימוש בו כאן הוא לתרגול אישי בלבד.

### ידנית

במסך "ניהול רשימות" בוחרים רשימה וכותבים זוג בכל שורה, עם רווח לפני ואחרי כל מקף:

```
שלום - مرحبا - מַרְחַבַּא
בית-ספר - مدرسة - מַדְרַסֵה
בוקר טוב - صباح الخير
```

התעתיק (החלק השלישי) הוא רשות.

### מקובץ JSON

נותנים שם לרשימה (חדשה או קיימת) ובוחרים קובץ שהוא מערך של מילים. מילים שכבר נמצאות ברשימה לא מתווספות שוב.

```json
[
  { "hebrew": "שלום", "arabic": "مرحبا", "transliteration": "מַרְחַבַּא" }
]
```

## המשחקים

- **כרטיסיות** – מוצגת המילה בעברית; לחיצה הופכת את הכרטיס ומציגה את הערבית והתעתיק.
- **אתגר 60 שניות** – מוצגת מילה בערבית וצריך לבחור את התרגום העברי מתוך עד ארבע אפשרויות, נגד השעון.
- **זיכרון** – עד 8 זוגות אקראיים מהרשימה; מתאימים קלף עברי לקלף ערבי.

## מסד הנתונים (Supabase)

טבלה בשם `word_lists`:

| עמודה | תוכן |
|---|---|
| `list_name` | שם הרשימה (ייחודי) |
| `words` | מערך JSON של מילים: `hebrew`, `arabic`, `transliteration` |

כתובת הפרויקט והמפתח הציבורי מופיעים בראש הסקריפט ב-`index.html` וב-`bookmarklet-src.js`.

## גיבוי

הרשימות מגובות אוטומטית לתיקייה `backups/latest/` במאגר, קובץ JSON לכל רשימה.

- **מתי:** GitHub Actions מריץ את `backup.py` בימי ראשון ורביעי בבוקר. גיבוי חדש נשמר רק אם משהו השתנה ברשימות.
- **הרצה ידנית:** בלשונית Actions בוחרים "גיבוי רשימות מילים" ולוחצים Run workflow. שימושי אחרי שמוסיפים הרבה מילים.
- **גרסאות קודמות:** התיקייה מכילה רק את המצב האחרון, אבל ההיסטוריה (History) של כל קובץ ב-GitHub שומרת את הגרסאות הקודמות שלו.
- **גיבוי למחשב:** `python backup.py` שומר את הרשימות בתיקייה `backups/<התאריך של היום>/`. הסקריפט משתמש רק בספרייה הסטנדרטית של פייתון.
- **שחזור:** במסך "ניהול רשימות" מייבאים את קובץ ה-JSON של הרשימה תחת "ייבוא מילים מקובץ JSON".


## עדכון הסימנייה

הסימנייה נוצרת מ-`bookmarklet-src.js`. אחרי שינוי בקוד צריך לייצר מחדש את הקישור שב-`bookmarklet-install.html` (הקוד, בלי הערות, אחרי `encodeURIComponent` ועם הקידומת `javascript:`), ולגרור שוב את הכפתור לסרגל הסימניות.
